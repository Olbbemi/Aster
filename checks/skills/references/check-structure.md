# check_structure.py

[공통 가이드라인](../guidelines.md)에 따라 기본 구조 검사 스크립트를 실행할 때 읽는 개별 안내다.
[검사 코드](../scripts/check_structure.py)는 지정한 스킬의 SKILL.md와 프론트매터만 검사한다.

## 적용 대상

생성하거나 유지하는 내부용/플러그인용 스킬을 대상으로 하며, 스킬별로 실행한다.
제거할 스킬에는 파일 존재를 요구하는 이 검사를 적용하지 않는다.
제거 여부와 남은 참조/등록의 확인은 호출 스킬에서 별도로 다룬다.

## 입력과 실행

`skill_directory`에 검사할 스킬 디렉토리의 절대 경로를 설정한다. SKILL.md 파일 자체를 넣지 않는다.
PyYAML이 필요하며 준비 방법과 허용 버전은 [공통 가이드라인](../guidelines.md)을 따른다.
Markdown 파서는 필요하지 않다.

```bash
python3 checks/skills/scripts/check_structure.py "$skill_directory" --json
```

## 검사 범위

| 검사 | 근거 |
| --- | --- |
| 정확한 `SKILL.md` 파일과 프론트매터 구분자 | 스킬 내부 배치 규격의 기본 구조, 내용 규격의 frontmatter |
| YAML 구문, 매핑과 필수 필드 | 검증 규격의 구조 검증, 내용 규격의 frontmatter |
| `name`/`description`의 비공백 문자열 | 필수 메타데이터의 형식과 검증 규격의 비어 있지 않은 설명 |
| 디렉토리명과 `name`의 일치, 이름 문자 집합 | 내용 규격의 frontmatter |

PyYAML SafeLoader로 파싱한다. YAML 1.1에서 boolean/숫자로 해석되는 값을 문자열로
사용하려면 따옴표로 감싼다. 명시적인 중복 YAML 키는 파싱 오류로 보고하며, YAML merge의
정상적인 상속/덮어쓰기는 허용한다. 자연어 문장의 중복 여부는 검사하지 않는다.

선택 필드는 없어도 통과한다. 현재 Aster에서 확정한 공용 필드별 형식이 없는 선택 필드는
YAML 구문만 검사하고 `UNCHECKED`로 출력한다. 이는 금지된 필드라는 뜻이 아니며,
형식과 지원 여부가 검증되었다는 뜻도 아니다.

## 결과와 한계

종료 코드와 공통 해석은 [공통 가이드라인](../guidelines.md)을 따른다. JSON에는 대상, 범위,
항목별 식별자/판정/설명/근거와 확인 가능한 줄 번호를 담는다. 이름의 허용 문자는 Aster 규격에 근거한다.

하네스별 `name` 길이/예약어와 `description` 길이 제한은 검사하지 않는다.
해당 제한이 없다는 뜻은 아니며, 지원 하네스의 기준 충족 여부는 호출 스킬에서 별도로 확인한다.

현재 검사는 Aster 스킬 규격의 기본 형식 검사다. 선택 필드 필요성, 본문의 의미,
링크, 배포 구성, 실제 CLI 발견/호출과 호환성은 통과 판정에 포함하지 않는다.
