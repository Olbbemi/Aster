# 스킬 내용 작성 규격

이 문서는 Aster에서 개발하는 스킬의 `SKILL.md`와 연결된 지침을 작성하는 기준을 정의한다.
파일별 역할과 배치는 `skill-layout.md`, 검증 항목과 판정 방법은 `skill-validation.md`에서 다룬다.

## 작성 목표

스킬은 에이전트가 이미 수행할 수 있는 일반적인 설명을 반복하지 않고, 해당 작업에서 판단과 결과를 실제로 바꾸는 지식, 절차와 제약을 제공한다.
한 사례나 임시 우회 방법을 모든 작업에 적용하는 규칙으로 확대하지 않는다.

지침의 구체성은 작업의 위험과 실패 비용에 맞춘다. 여러 방법이 성립하는 작업은 목표와 판단 기준을 제시한다.
순서나 값이 달라지면 실패하거나 일관된 반복 실행이 필요한 작업은 고정 절차나 실행 스크립트로 수행 방법을 제한한다.

## `SKILL.md` frontmatter

`SKILL.md`는 YAML frontmatter에 다음 두 필드를 반드시 둔다.

```yaml
---
name: skill-name
description: 이 스킬이 하는 일과 사용해야 하는 조건을 설명한다.
---
```

- `name`은 스킬 디렉토리 이름과 일치시킨다.
- `name`에는 소문자 영문자, 숫자와 하이픈만 사용한다.
- `description`은 스킬이 하는 일과 적용할 조건을 함께 설명한다.
- `description`은 비슷하지만 적용 대상이 아닌 요청을 실제로 구분해야 할 때만 제외 조건을 포함한다.
- 상세 절차, 도구 사용법과 긴 기능 목록은 `description`에 넣지 않는다.
- 대상 하네스가 허용하는 선택 필드는 필요성과 지원 여부가 확인된 경우에만 추가한다.

이름 길이, 설명 길이와 예약어처럼 하네스별 제한이 다른 항목은 모든 대상 하네스의 제한을 충족해야 한다.

## `SKILL.md` 본문

본문에는 스킬이 적용된 뒤 항상 필요한 내용만 둔다.

- 스킬의 목적과 책임 범위
- 필요한 입력과 입력이 부족할 때의 대응
- 기대 결과의 제공 형태와 충족 기준
- 작업을 시작하고 완료하는 데 필요한 핵심 흐름
- 결과에 영향을 주는 제약, 실패 및 중단 조건과 해당 조건이 발생했을 때의 대응
- 상황별로 읽거나 실행할 자료와 그 조건
- 사용자가 정해야 하거나 승인해야 하는 시점이 실제로 있는 경우 그 조건

사용자 요청의 범위를 넓히지 않으며, 스킬이 적용되었다는 사실만으로 외부 변경이 승인되었다고 해석하는 지침은 작성하지 않는다.
저장소나 조직의 공통 운영 규칙을 스킬에 복제하지 않고 해당 규칙을 정의한 문서를 참조한다.
참조할 문서가 대상 환경에 함께 제공되지 않는다면 스킬이 독립적으로 수행되는 데 필요한 내용만 스킬 배포 경계 안에 둔다.

## 단계적 공개

스킬 정보는 다음 순서로 필요한 만큼만 제공한다.

1. `name`과 `description`은 스킬 선택에 필요한 정보만 제공한다.
2. `SKILL.md` 본문은 선택된 스킬의 공통 흐름과 핵심 제약을 제공한다.
3. 참조 문서와 실행 자료는 현재 작업 조건에 해당할 때만 읽거나 실행한다.

`SKILL.md` 또는 상위 참조 문서에서 어떤 상황에 어느 파일을 읽거나 실행해야 하는지 명시한다.
문서에 적는 상대 경로는 기준 위치를 명시하고, 다른 기준을 사용하는 경로는 해당 위치에서 별도로 설명한다.
단순한 스킬은 내용을 불필요하게 여러 파일로 나누지 않는다.

## 연결 자료 작성 기준

### 참조 문서

- 한 문서는 하나의 구분 가능한 주제나 작업 조건을 맡는다.
- 문서를 이해하는 데 필요한 관련 자료는 해당 문서에서 직접 참조한다.
- 권위 있는 외부 문서를 그대로 복제하지 않는다. 스킬의 판단에 필요한 Aster 고유 내용은 직접 작성하고, 외부 문서는 원문 위치를 참조한다.
- 긴 문서는 필요한 내용을 찾을 수 있도록 목차나 검색어를 제공한다.

### 스크립트

- 반복 처리나 결정적 실행이 정확성과 재현성을 높일 때 사용한다.
- 지침에서 스크립트를 실행할 경우와 스크립트의 구현을 참고할 경우를 구분한다.
- 실행하도록 지정한 스크립트는 실행 명령 또는 호출 방법, 인수와 필요한 실행 환경을 명시한다. 작업 디렉토리가 실행 결과나 경로 해석에 영향을 주면 실행할 위치도 명시한다.
- 필요한 입력, 생성하거나 변경하는 대상, 정상 결과와 실패 동작을 명시한다.
- 실행 환경에 없는 의존성이 필요하면 준비 방법과 사용할 수 없을 때의 중단 조건을 지침에 명시한다.

### 에셋

- 결과물에 포함하거나 결과물을 만드는 데 사용할 자료와 그 용도를 지침에 명시한다.
- 해당 자료를 작업 지침으로 취급하여 항상 읽도록 요구하지 않는다.
- 출처, 사용 조건이나 수정 제한이 결과에 영향을 주면 함께 기록한다.

## 하네스 호환성

이 문서에서 대상 하네스는 대상 스킬 명세서에 지원 대상으로 정의한 CLI를 뜻한다.
지원 범위를 제한하는 버전이나 실행 환경 조건이 있으면 함께 적용한다.

둘 이상의 지원 CLI에서 함께 사용할 스킬은 해당 CLI들이 공통으로 지원하는 `SKILL.md`와 스킬 내부 자료를 우선한다.
호출 표기, UI 메타데이터, 정책 필드와 실행 환경은 한 CLI에서 동작했다는 이유로 다른 지원 CLI에서도 지원된다고 간주하지 않는다.

지원 CLI 사이에서 실제로 호환되지 않는 사항이 확인되어 공용 구성만으로 요건을 충족할 수 없다면, 필요한 전용 내용을 공통 지침과 분리하고 적용할 CLI를 파일 또는 단락에 명확히 밝힌다.
CLI별 기대 결과와 허용할 차이는 대상 스킬 명세서를 기준으로 하며, 검증은 [스킬 검증 규격의 하네스 및 배포 검증](skill-validation.md#하네스-및-배포-검증)을 따른다.
