# 스킬 내부 배치 규격

이 문서는 Aster에서 개발하는 스킬 디렉토리 내부의 파일과 하위 디렉토리 역할, 배치 기준과 생성 조건을 정의한다.
저장소 안에서 스킬 자체를 둘 위치와 공용 자료의 위치는 Aster 저장소의 `standards/repository-layout.md`를 따른다.
`SKILL.md`의 작성 규칙은 `skill-content.md`, 검증 항목과 판정 방법은 `skill-validation.md`에서 다룬다.

## 기본 구조

스킬 전용 자료는 스킬 이름과 같은 디렉토리 안에 둔다.
아래 구조에서 `SKILL.md`는 필수이며, 나머지 하위 디렉토리는 해당 역할의 자료가 있을 때만 만든다.
지원 대상 CLI에서만 필요한 파일이나 디렉토리를 추가할 때는 [스킬 내용 작성 규격의 하네스 호환성](skill-content.md#하네스-호환성)을 확인하고,
해당 CLI에서 요구하는 배치 위치와 형식을 실제 근거로 확인한다.

```text
<skill-name>/
|-- SKILL.md
|-- references/
|-- scripts/
`-- assets/
```

## 항목별 역할

| 항목 | 필수 여부 | 역할 |
| --- | --- | --- |
| `SKILL.md` | 필수 | 스킬의 식별 정보, 적용 조건, 핵심 지침과 필요한 자료의 진입점을 정의한다. |
| `references/` | 선택 | 특정 상황에서만 읽을 상세 지침, 규격, 스키마와 절차를 둔다. |
| `scripts/` | 선택 | 스킬의 작업 수행을 위해 실행하거나 구현 방법을 참고할 코드를 둔다. |
| `assets/` | 선택 | 결과물에 포함하거나 결과물을 만드는 데 사용할 템플릿, 이미지, 글꼴과 기본 프로젝트를 둔다. |

## 배치 기준

- 스킬을 선택하는 데 필요한 정보와 선택된 뒤 항상 필요한 지침은 `SKILL.md`에 둔다.
- 특정 조건에서만 필요한 상세 내용은 `references/`에 두고, 해당 자료를 읽을 조건을 `SKILL.md` 또는 연결된 참조 문서에 명시한다.
- 스킬의 작업 수행을 위해 실행하거나 구현 방법을 참고할 코드는 `scripts/`에 둔다.
- 코드의 실행 또는 참조 조건과 필요한 사용 안내는 `SKILL.md` 또는 연결된 참조 문서에 명시한다. 특정 조건에서만 필요한 상세 설명은 `references/`에 둔다.
- 결과물에 포함하거나 결과물을 만드는 데 사용할 파일은 `assets/`에 둔다. AI 에이전트가 따라야 할 작업 지침은 `assets/`에 두지 않는다.
- 코드 파일도 결과물에 복사하거나 수정하여 사용할 템플릿 또는 기본 프로젝트의 구성 요소라면 `assets/`에 둔다.
- 스킬이 제공하는 파일 사이의 참조는 스킬이 실제 배치되는 위치에서 성립해야 한다.
  플러그인 배포용 스킬의 동작에 필요한 파일은 플러그인의 배포 경계 안에 두고, 설치된 위치에서 참조할 수 있어야 한다.
- `references/`, `scripts/`, `assets/` 안의 추가 하위 디렉토리는 자료를 역할이나 작업 조건에 따라 더 나눌 필요가 있을 때만 만든다.
