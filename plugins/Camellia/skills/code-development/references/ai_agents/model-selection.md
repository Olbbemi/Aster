# 모델과 추론 강도 선택

설계에서 구현에 사용할 모델을 논의하거나 교차 검증의 모델을 선택할 때 읽는다.
상대 경로는 이 파일이 있는 references/ai_agents/ 디렉토리를 기준으로 한다.
상대 CLI의 호출 방법과 옵션은 [교차 검증 실행 안내](review-execution.md)를 따른다.

## 모델과 추론 강도의 의미

| 구분 | 의미 |
| --- | --- |
| 모델 | 작업을 수행하는 AI의 기본 능력과 특성이다. 문제 이해, 해결 방법 탐색과 판단 능력에 영향을 준다. |
| 추론 강도 | 선택한 모델이 문제 해결에 들이는 분석과 검토 노력의 수준이다. 모델 자체를 바꾸는 설정은 아니다. |

low는 짧고 판단 기준이 명확한 작업, medium은 일반 작업, high는 복잡한 조건과 영향 검토의 시작점으로 권장한다.

추가로 깊은 검토가 필요하면 다음 강도를 고려한다. 아래 상황은 이 스킬의 작업에 적용한 권장 예시다.

- xhigh: 여러 제약과 대안이 얽힌 설계, 복잡한 상태 변화나 회귀 원인 분석처럼 high보다 깊은 검토가 필요한 경우에 고려한다.
- max: xhigh로도 해소하기 어려운 핵심 쟁점이나 특히 어려운 설계 판단에서, 시간과 토큰 사용보다 검토 깊이가 중요한 경우에 제한적으로 고려한다. 일상적인 구현과 검토의 기본값으로 두지 않는다.

높은 강도는 복잡한 작업에 도움이 될 수 있지만 시간과 토큰 사용이 늘어날 수 있으며, 결과의 품질을 보장하지 않는다.
같은 강도 이름도 모델 간 동일한 연산량이나 성능을 뜻하지 않는다.

## 공통 선택 기준

- 아래 표는 권장 조합이며 필수 조건이 아니다. 사용자가 지정한 모델과 추론 강도를 우선한다.
- 파일 종류나 개수만으로 결정하지 않고, 판단의 복잡도와 오류의 영향 범위를 고려한다.
- 여러 용도가 섞이면 핵심 판단에 맞춰 선택한다. 표의 각 행을 별도의 필수 작업이나 호출로 취급하지 않는다.
- 많은 제약이 얽히거나 중요한 쟁점이 해소되지 않으면 상위 모델이나 위 기준에 따른 추론 강도 상향을 검토한다. 모든 강도를 순서대로 실행할 필요는 없다.
- 실행 환경에서 모델과 추론 강도를 지원하는지 확인한다. 권장 조합을 사용할 수 없으면 가능한 대안과 차이를 확인하고, 실제 선택한 조합을 명확히 한다.
- 구현에 권장한 조합과 실제 사용한 조합을 구분한다. 현재 세션의 모델을 변경할 수 없으면 변경했다고 보고하지 않는다.

## 용도 구분

| 용도 | 주요 작업과 판단 |
| --- | --- |
| 일반 기능과 테스트 작성 | 명확한 설계에 따른 기능 및 테스트 코드 작성 |
| 복잡한 구현과 리팩터링 | 여러 모듈 연결, 복잡한 상태 처리와 기존 동작을 유지하는 구조 변경 |
| 요건과 구조 설계 | 요구사항, 제약, 구성 요소의 역할과 연결 관계 정리 |
| 표현과 형식 검토 | 오탈자, 명칭, 링크와 정해진 양식의 누락 확인 |
| 개별 로직 검토 | 함수나 기능의 조건 분기, 경계값과 예외 처리 확인 |
| 테스트 적절성 검토 | 요구사항의 검증 범위, 누락된 사례와 잘못된 성공 판정 확인 |
| 연관 동작과 변경 영향 검토 | 모듈 간 상태 변화, 동시성, 재시도와 회귀 영향 확인 |
| 설계와 규칙의 전체 일관성 검토 | 요구사항/설계/구현의 정합성, 지침 충돌과 누락 및 단계 연결 확인 |

검토의 수행 시점은 [교차 검증 지침](../guidelines.md#검토-대상과-수행-시점)을 따른다.

## Codex

이 안내에서 다루는 모델과 추론 강도는 다음 순서로 읽는다. 오른쪽으로 갈수록 모델의 전반적인 능력 수준이나 추론 강도가 높아지는 방향이다.

- 모델: GPT-5.6 Luna -> GPT-5.6 Terra -> GPT-5.6 Sol -> GPT-6 Astra
- 추론 강도: low -> medium -> high -> xhigh(Extra High) -> max

모델 순서는 공식 설명을 바탕으로 정리한 대략적인 선택 기준이며, 모든 작업에서 결과가 이 순서대로 좋아진다는 뜻은 아니다. 추론 강도는 같은 모델 안에서 비교하며 실제 지원 범위는 호출 환경에서 확인한다.

| 용도 | 권장 모델 | 추론 강도 |
| --- | --- | --- |
| 일반 기능과 테스트 작성 | GPT-5.6 Terra | medium |
| 복잡한 구현과 리팩터링 | GPT-5.6 Sol | high |
| 요건과 구조 설계 | GPT-6 Astra | high |
| 표현과 형식 검토 | GPT-5.6 Luna | low |
| 개별 로직 검토 | GPT-5.6 Terra | medium |
| 테스트 적절성 검토 | GPT-5.6 Terra | high |
| 연관 동작과 변경 영향 검토 | GPT-5.6 Sol | high |
| 설계와 규칙의 전체 일관성 검토 | GPT-6 Astra | high |

## Claude

모델 계열과 추론 강도는 다음 순서로 읽는다. 오른쪽으로 갈수록 모델의 전반적인 능력 수준이나 추론 강도가 높아지는 방향이다.

- 모델 계열: Haiku -> Sonnet -> Opus -> Fable
- CLI 별칭: haiku -> sonnet -> opus -> fable
- 추론 강도: low -> medium -> high -> xhigh -> max

모델 순서는 공식 문서의 계열별 용도 설명을 바탕으로 정리한 대략적인 선택 기준이며, 모든 작업에서 결과가 이 순서대로 좋아진다는 뜻은 아니다. 별칭이 가리키는 실제 모델 버전은 제공자와 설정에 따라 달라질 수 있다. 추론 강도는 같은 모델 안에서 비교하며, 모델과 강도의 실제 사용 가능 여부는 호출 환경에서 확인한다.

| 복잡한 구현과 리팩터링 | Opus 5 | high |
| 요건과 구조 설계 | Opus 5 | high |
