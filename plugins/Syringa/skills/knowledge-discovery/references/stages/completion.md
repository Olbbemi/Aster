# 종료와 결과 확인 단계 수행 지침

- 단계 식별자: `completion`.
- 상대 링크는 이 문서가 있는 디렉토리를 기준으로 한다.

## 공통 흐름과의 연결

시작, 분기와 재개는 [진행 흐름](../workflow.md)을 따른다.
스크립트의 인자와 데이터 형식은 [실행 계약](../execution.md)에서 확인한다.

## 단계 역할

실제 실행 상태를 확인하고 저장 결과와 남은 작업을 구분하여 보고한다.

## 입력과 시작 시 확인

실행 생성 이후의 명시된 `run`을 사용한다.
준비 중 실행 생성 자체가 실패했다면 상태 조회를 시도하지 않고 해당 오류를 보고한다.

## 수행 흐름

`run_status.py`로 실제 저장 결과를 확인하고 완료된 주제와 출력 파일 위치를 보고한다.
출력 파일 위치를 사용자에게 알리는 것은 결과 본문에 원본 출처를 넣는 것과 구분한다.

일부 실패 시 이미 저장된 파일은 보존하고 실패한 주제, 미처리 주제와 이유를 구분한다.
명시적 중단 요청이 오면 새 주제 처리를 멈추고 저장 완료된 범위만 보고한다.
저장되지 않은 내용을 저장 완료로 기록하지 않는다.

실행이 생성된 이후에는 완료, 빈 결과, 전체 제외, 중단 또는 실패를 보고하기 전에 상태를 조회한다.
`run_status.py`가 호출 자체의 오류를 반환하거나 결과에 복구 필요 오류를 포함하면 이를 별도로 보고한다.
복구 필요 상태를 해소하기 전에는 저장을 재시도하거나 새 파일을 무조건 만들지 않는다.

## 완료 확인과 인계

완료 보고는 조회로 확인한 결과에 한정한다.
재개할 작업이 있으면 [진행 흐름의 재개 기준](../workflow.md#재개)에 따라 해당 단계로 돌아간다.
