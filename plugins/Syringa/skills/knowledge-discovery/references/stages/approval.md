# 일괄 승인 단계 수행 지침

- 단계 식별자: `approval`.
- 상대 링크는 이 문서가 있는 디렉토리를 기준으로 한다.

## 공통 흐름과의 연결

시작, 분기와 재개는 [진행 흐름](../workflow.md)을 따른다.
스크립트의 인자와 데이터 형식은 [실행 계약](../execution.md)에서 확인한다.

## 단계 역할

사용자 답변을 등록된 후보 ID에 대응시키고 승인 집합을 고정한다.

## 입력과 시작 시 확인

등록된 후보 목록과 `proposal_digest`, 실제 사용자 선택 답변을 사용한다.
사용자에게 제시한 목록과 실행 상태의 목록이 같은지 확인한다.

## 수행 흐름

### 승인 범위 확정

"모두", 명시 목록, "이 두 개는 제외"처럼 대상을 명확히 정할 수 있는 답을 승인 집합으로 해석한다.
제외 요청은 제시한 후보 중 나머지를 승인한 것으로 처리한다.
동일한 키워드가 여러 주제에 있거나 제외 대상이 불명확하면 의미를 확인한다.
답이 없거나 모호하면 상세 분석과 저장을 시작하지 않는다.

확정한 후보 ID, 해당 후보 목록의 식별값과 사용자 답변을 `approve_candidates.py`에 전달한다.
승인하지 않은 항목을 상세 분석하거나 추가하지 않는다.
등록 후 자료나 후보가 바뀌면 기존 승인을 다른 목록에 재사용하지 않는다.

## 완료 확인과 인계

승인된 후보가 있으면 [상세 분석과 저장](analysis-and-save.md)으로 이동한다.
명시적 전체 제외는 빈 승인 집합으로 등록하고 [종료와 결과 확인](completion.md)으로 이동한다.
답변이 없거나 모호하면 이 단계에 머문다.
