# 실행 모델 확인

자료 규모와 필요한 해석 수준을 확인하고
[Aster 공용 모델 선택 기준](https://github.com/Olbbemi/Aster/blob/main/shared/model-selection.md)을 참고한다.
기준 표를 이 스킬에 복제하지 않는다.
기준을 읽을 수 없으면 그 사실을 알리며, 최신 내용을 추정해 제시하지 않는다.
사용자가 지정한 모델과 강도가 있으면 해당 지정을 우선한다.

현재 대화에서 이번 자료 분석에 적용되는 승인된 모델과 강도가 있는지 확인한다.

- 기존 승인이 있으면 그 범위에서 계속한다.
  후보나 주제마다 모델을 다시 제안하거나 승인받지 않는다.
- 기존 승인이 없으면 1차 후보 추출과 승인 후 2차 상세 분석을 하나의 작업 묶음으로 제안하여 확인받는다.

입력 규모 때문에 승인한 범위를 변경해야 하는 경우에만 새 범위를 설명하고 확인한다.

하네스에서 실제 설정을 확인할 수 있으면 확인한다.
확인할 수 없으면 사용자 설정 확인을 받고, 직접 검증한 사실과 구분한다.
모델 전환을 스스로 수행했거나 자동 적용했다고 주장하지 않는다.

승인된 모델과 강도, 승인 근거와 설정 확인 방식을 실행 상태의 `model`에 남긴다.
이는 내부 실행 기록이며 후보 결과 파일에 추가하는 메타데이터가 아니다.
