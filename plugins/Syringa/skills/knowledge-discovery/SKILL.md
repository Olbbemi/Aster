# Knowledge Discovery

## 목적과 적용 범위

사용자가 지정한 코드와 명세서에서 일반 기술 지식 후보를 추출한다.
주제별 후보를 먼저 제시하고 일괄 승인된 항목만 상세 분석하여 주제별 파일에 저장한다.
프로젝트 고유 구조 분석, 대화 학습 기록과 완성 위키 작성은 제외한다.

## 필수 입력

분석 대상 경로와 저장 기준 경로를 모두 사용자에게 입력받는다.
현재 디렉토리, 이전 실행, 프로젝트 이름으로 누락값을 추정하지 않는다.
둘 중 하나라도 없으면 누락 입력을 요청하고 자료 분석을 시작하지 않는다.

## 시작과 재개

이 문서의 상대 경로는 스킬 디렉토리를 기준으로 해석한다.
[진행 흐름](references/workflow.md)을 읽고 현재 상태에 해당하는 단계 문서로 진행한다.
새 실행은 준비 단계에서 시작하며, 기존 실행은 같은 문서의 재개 기준을 따른다.

단계별 수행 내용과 스크립트 호출 시점은 단계 문서에서 관리한다.
명령 인자, 입력과 응답 및 오류는 [실행 계약](references/execution.md),
모델 확인과 승인 범위는 [모델 선택 절차](references/model-selection.md)를 따른다.
